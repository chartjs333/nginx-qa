# Внешний этап приёмки исправленного мастера

Код, локальный экземпляр и документация переданы. Полная автономная эксплуатация
остаётся **NO_GO**. Координатор запрашивает **BLOCKED_EXTERNAL**, сохраняя
выполненную работу и её проверки. Это не утверждение, что вся исходная цель
пользователя уже достигнута.

Движок принял исправленный release commit
`c7fa6a42a15b71a1c724e596472fe1f29463074d` с двумя независимыми APPROVE именно
для честного результата NO_GO. Обе квитанции включены в
`evidence/corrective-continuity/`. Этот новый документ также проходит отдельные
проверки; их будущие решения не подменяются заранее вписанными APPROVE.

## Что сохранено

- 148 тестов продукта; отдельно 12 тестов безопасной команды входа.
- Настоящий браузерный Apply с конкретной новой квитанцией и тем же ID после reload.
- Настоящий native self-test в отдельном проекте9010, опубликованный коммит
  `f1148f56787fd905d6880583e89205b9b67cdab9` и два независимых Reviewer.
- Освобождение reservations/lease, идемпотентный повтор, перезапуск своего сервера
  и восстановление доступа того же именованного оператора.
- История двух обнаруженных при ревью дефектов и выданных движком доработок.
- Работающий приватный мастер18038, исходники `D:/nq-sdw-delivery`,
  [draft PR18](https://github.com/chartjs333/nginx-qa/pull/18) поверх PR17.

Прежние серверы и main не изменялись. Временные исполнитель и Git daemon
остановлены. Инструкции входа, запуска и остановки:
[corrective-delivery.md](corrective-delivery.md).

## Что требуется для продолжения

1. Предоставить поддерживаемый хост с требуемой изоляцией и подходящим Codex CLI.
   На текущей Windows10 требуемый MXC backend недоступен; одного обновления CLI
   недостаточно. `--check` должен успешно подтвердить реальную границу изоляции.
   Не заменять её ранее отвергнутым слабым режимом или фиктивной декларацией.
2. Настроить и проверить настоящий tool-free LLM-консультант. Сейчас ответ явно
   детерминированный. Защищённый provider/model/secret reference и живой
   проверенный ответ нужны отдельно; новый платный ресурс не создавался.
3. Опубликовать свежий неизменяемый self-test profile с новыми manifest commit
   и ветками. Провести реальный автономный запуск через тот же Managed Engine,
   получить реальные result commit и две независимые проверки, доказать
   завершение/Stop и освобождение ресурсов. Старый завершённый профиль не
   переименовывать в новый результат и не обходить один активный спринт на проект.
4. Завершить отдельные внешние gates Telegram/мобильного входа/туннеля из PR17.
   Затем повторно оценить выпуск и PR. Автоматического объединения с main нет.

После принятия этого документа следует штатное native `BLOCK_EXTERNAL` только
для фактического контекста данного результата. Его квитанция
`RECOVERY_COMPLETED`, окончательный статус и независимые решения сохраняются
отдельно в `C:/nqt35/client/sdw-corrective-20261104/FINAL_DELIVERY.json`.
Текущий документ не обещает, что ещё не полученная квитанция уже существует.
Возобновление возможно через поддерживаемый recovery/repair или новый
разрешённый спринт; ручное редактирование control DB и принятой истории запрещено.
